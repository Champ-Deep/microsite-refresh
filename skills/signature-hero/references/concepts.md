# Concept library

Each concept is an opening scene, a first scroll and a landed object. Pick by what the catalog sells and the one action. Invent new ones from the site's own data and add them here once an owner approves them.

## 1. Living data globe (built: LakeB2B, Oct 2026)
Fits: lists sold by country or region; coverage is the selling point.
```
[opening]            [mid-scroll]             [landed]
 eyebrow             headline lifts away      copy left | globe right
 WELCOME TO THE      globe rises out of       hover market -> glass card
 living data world   the horizon, turning     click -> pin, CTA "Get a
 ~~~~ glow ~~~~      ~~~~~~(  o  )~~~~~~      sample for Germany"
                                              chips re-cut markers + arcs
```
Data: per-market contacts, companies, industry split, top titles. 21st.dev query: "globe". Engine: cobe.

## 2. File scanner
Fits: verification, append, hygiene sites (Email Data Group, QuickAppend).
```
[opening]            [mid-scroll]             [landed]
 a CSV page drifts   rows stream through a    drop zone; your own file
 under a light bar   scanner line; bad rows   gets the same scan; graded
                     flash magenta, good      report with counts
                     rows turn gold
```
Data: sample rows (labelled), verdict mix. 21st.dev query: "file upload", "scanner", "data table animation".

## 3. Stack constellation
Fits: technology install lists (who uses Salesforce, AWS, HubSpot).
```
[opening]            [mid-scroll]             [landed]
 dots of light       dots cluster into tech   pick a technology -> its
 scattered on navy   logos; lines link the    cluster glows, count of
                     ones that co-occur       companies + CTA prefills
```
Data: install counts and co-install pairs. 21st.dev query: "orbit", "network graph", "particles".

## 4. Org chart pulse
Fits: title and role lists (C-suite, HR heads, clinicians).
```
[opening]            [mid-scroll]             [landed]
 one glowing node    an org tree grows        hover a role -> card with
                     downward, level by       count and sample titles,
                     level, as you scroll     filter by industry
```
Data: title taxonomy counts. 21st.dev query: "tree", "org chart", "node graph".

## 5. Market map
Fits: single-country or state lists (US healthcare, UK SMB).
```
[opening]            [mid-scroll]             [landed]
 coastline traces    states fill in as a      hover state -> card, click
 itself in light     heat map by count        -> pin and prefill, chips
                                              re-cut by specialty
```
Data: per-state counts. 21st.dev query: "map", "choropleth".

## 6. Inbox arrival
Fits: email lists and campaign data sites.
```
[opening]            [mid-scroll]             [landed]
 an empty inbox      messages land one by     filters (industry, title)
 card, cursor blink  one, sorted by segment   reshuffle the inbox, open
                                              one -> sample record
```
Data: sample records (labelled). 21st.dev query: "inbox", "mail list animation".

## 7. List stack
Fits: catalog-heavy sites with many niche lists.
```
[opening]            [mid-scroll]             [landed]
 one card            cards fan out into a     search or tap a category
                     3D stack by category     -> the stack flips to it,
                                              two clicks to any list
```
Data: `catalog.json` groups. 21st.dev query: "card stack", "3d carousel".

## Questions to generate new concepts
- What does a buyer picture when they think of this data: a place, a person, a company, a file?
- What would they like to touch: their own market, their own file, their own title?
- What changes when they choose, and how does that show up in the CTA?
